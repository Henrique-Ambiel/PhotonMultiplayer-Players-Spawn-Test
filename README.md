# Teste de Multiplayer com Photon PUN na Unity 🎮🕹️
Este repositório contém um projeto desenvolvido em Unity como primeiro contato com a ferramenta Photon PUN (Photon Unity Networking). O objetivo principal foi explorar o funcionamento básico de uma conexão multiplayer e realizar um teste de spawn de players em um lobby.

## Objetivo do Projeto 🚀
- Entender os fundamentos de jogos multiplayer na Unity.

- Aprender a integrar o Photon PUN à Unity.

- Criar um lobby funcional que permite o spawn automático de jogadores ao entrarem no jogo.

## Funcionalidades Implementadas ⚙️
- Conexão com os servidores da Photon.

- Criação e entrada automática em salas (rooms).

- Instanciação (spawn) de múltiplos players na cena, com controle separado.

## Tecnologias e Ferramentas Utilizadas 🛠️
- Unity Engine

- Photon PUN 2 (Free)

- C#

## Aprendizados 💡
Esse projeto marcou meu primeiro contato com desenvolvimento multiplayer em Unity. Com ele, aprendi:

- Como conectar um jogo à Photon Cloud.

- O básico de criação e gerenciamento de salas.

- A lógica para sincronizar o spawn de jogadores entre clientes conectados.
